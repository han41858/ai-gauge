# 권한과 개인정보

| 권한 | 목적 |
| --- | --- |
| `storage` | 설정·최신 정상 스냅샷·오류·재시도 시각 저장과 열린 탭 간 결과 공유. 메모리 기반 세션 저장소에는 서비스별 티켓 검증 완료 boolean만 보관. 이력·원본 응답·계정 식별자는 저장하지 않음 |
| `alarms` | 정상 10분 수집, 1분마다 갱신/재시도/초기화 기한 검사 및 서비스 워커 재시작 복구 |
| `scripting` | 선택 권한 승인 후 번들 안의 고정 수집 함수와 표시줄 실행. 기존 로그인 세션을 동일 출처에서 사용 |
| 선택 호스트 | `https://chatgpt.com/*`, `https://claude.ai/*`, `https://gemini.google.com/*`. 최초 선택한 호스트를 한 번에 승인하고 이후 서비스별 철회 가능. 허용된 탭 실행과 탭 없는 워커 요청에 같은 권한 사용 |

`tabs`, `cookies`, `activeTab`, `webRequest`, `<all_urls>`, `clipboardWrite` 권한은 요청하지 않습니다. 호스트 권한으로 허용된 탭을 식별하고 그 탭의 `tabId`에 배지를 설정합니다. URL·탭 ID는 저장하거나 전송하지 않으며, 지원하지 않는 탭과 URL을 읽을 수 없는 탭의 배지는 비웁니다.

## 수집과 인증

- ChatGPT와 Codex는 한 ChatGPT 플랜 수집과 스냅샷을 공유합니다. 세션 bearer는 페이지 또는 워커의 수집 함수 안에서 해당 요청에만 사용하고 정규화 결과에 반환하지 않습니다. 일반 채팅의 메시지·모델별 quota 관찰은 하지 않습니다.
- Claude의 조직 UUID도 수집 함수 안에서만 사용합니다. 여러 조직이면 임의의 조직을 고르거나 합산하지 않습니다.
- Gemini는 열린 페이지의 CSRF 정보 또는 탭이 없을 때 고정 `/app` 응답에서 확인한 요청 토큰을 `gemini.google.com`의 `jSf9Qc` 사용량·`otAQ7b` 요금제 정책 요청에만 사용합니다. `/app` HTML은 크기 제한이 있는 스트림으로 읽고 실제 script의 `WIZ_global_data` JSON에서 `SNlM0e`만 추출하며 토큰 발견 시 읽기를 중단합니다. HTML·원격 스크립트는 실행하지 않고 대화·프로필 데이터는 해석하지 않습니다. 토큰·HTML은 저장·로그·UI 반환하지 않습니다. 정책 조회 후 bootstrap 맥락을 재확인할 수 없으면 요금제만 제외합니다. 자세한 경계는 [탭 없는 수집](background-collection.md)을 참고하세요.
- 수집 함수의 결과는 허용된 사용량 필드로 축소한 후 확장에서 다시 검증합니다. 원본 API 응답·예외 body·쿠키·계정·인증정보를 저장하거나 로그하지 않습니다.
- 요금제는 ChatGPT의 기존 `plan_type`, Claude의 기존 조직 capability/tier를 사용하며 Gemini만 같은 출처의 읽기 전용 `otAQ7b` 정책 RPC를 추가합니다. 결제·구독 변경 API와 새 Chrome 권한은 없습니다. 저장되는 요금제 정보는 확인된 표시 이름·확인 시각과 재확인 대기 여부뿐입니다. 정책 원문·planId·추가 계정 식별자는 저장하지 않습니다.
- 초기화 티켓은 기존 ChatGPT 사용량 요약과 추가 상세 GET, Claude의 `usage?cedar_ember=1` 및 조직 재확인으로 조회합니다. ID·인증정보는 수집 요청 안에서만 사용하고 정규화 결과에 반환하지 않습니다. ChatGPT 계정 비교 해시는 워커 메모리에만 두며 정상 스냅샷과 UI에는 전달하지 않습니다. 티켓 소비·결제 API와 새 권한은 없습니다.
- 마지막 활성 창의 허용된 서비스 탭을 우선하며, 실패 후 다른 탭/계정으로 순회하지 않습니다. 해당 서비스 탭이 실제로 없을 때만 워커에서 `credentials: include`, `cache: no-store`, `redirect: error`로 고정 서비스 URL을 요청합니다. 정지·폐기된 탭만 있는 경우에는 기본 쿠키 계정으로 바꾸지 않습니다. 쿠키는 브라우저가 처리하며 직접 읽거나 헤더를 만들지 않습니다. 숨은 탭·오프스크린 문서도 만들지 않습니다.
- 탭 없는 요청은 브라우저 쿠키 세션의 기본 계정을 사용합니다. 같은 Chrome 프로필에서 계정을 변경하면 새로고침해야 합니다. 자동 계정 전환·계정 합산은 없으며 쿠키 정책·서비스 보호 정책에 따른 실제 로그인 호환성은 미검증입니다. 기존 사용자 확인은 열린 탭 수집에 대한 것으로 새 워커 경로의 검증을 대신하지 않습니다.

## 권한·표시 수명

최초 실행에는 기본 선택된 세 서비스의 체크박스를 제공하고 사용자가 고른 호스트만 하나의 `permissions.request`로 요청합니다. 사용자 클릭에 이어서 권한을 요청하며 새 선택 호스트 권한을 승인하면 백그라운드가 같은 동작에서 서비스를 켜고 갱신합니다. 승인 창 때문에 팝업이 닫혀도 두 번째 클릭은 필요하지 않습니다. 취소하면 서비스를 켜지 않습니다. 한 서비스라도 활성화되거나 권한이 있으면 기존 카드별 관리 화면을 표시하고 기존 권한이 유지된 꺼진 서비스를 워커 재시작만으로 켜지 않습니다.

ChatGPT 권한 철회는 일반 채팅·Codex의 수집과 표시 모두에 적용됩니다. Claude와 Gemini는 각각 독립적입니다. 표시 설정은 ChatGPT·Codex·Claude·Gemini 네 화면으로 구분하고 수집은 세 서비스만 존재합니다.

표시줄은 입력 요소·중지 버튼·래퍼의 존재·속성·구조·레이아웃만 검사합니다. 입력 값·대화 본문·첨부·이력은 읽지 않습니다. Codex의 루트 리다이렉트는 허용된 ChatGPT 호스트 안에서만 보완 판별하며 권한·발신자 검증을 넓히지 않습니다. Gemini의 초기 셀렉터는 공개 참고의 가정에 기반하며 실제 사이트 확인이 필요합니다.

동일 확장 ID와 허용된 페이지/프레임의 메시지만 처리합니다. 일괄 활성화 메시지는 허용된 팝업만 보낼 수 있고 중복·미지원 서비스·추가 필드를 거부합니다. 일반 페이지의 임의 메시지를 사용량 원본으로 신뢰하지 않습니다. DOM에는 textContent로 삽입하고 원격 코드·동적 코드를 실행하지 않습니다.

권한 철회 시 실행 중 요청의 늦은 응답을 게시하지 않으며 표시 노드·이벤트·예약을 정리합니다. Chrome이 실행한 content script 자체를 회수할 수는 없습니다. 일반적인 일시 통신 실패에는 기존 표시를 유지하고 로컬 상태 조회를 재시도합니다.

## UI와 진단

팝업에는 실제 제한별 정보를 표시하고 배지·입력창은 실제 유효 사용률의 최댓값을 선택합니다. 합산·소진 예측·기간 강제 생성은 하지 않습니다. 배지 선택, 사용률 임계치, 수집 시각 및 갱신 주기 설정은 없습니다. 과거 호환용 설정 필드가 남아 있어도 현재 표시 정책에 사용하지 않습니다.

개발 빌드의 접힌 진단은 버전, 서비스별 켜기·권한·상태·오류·내부 시각, 화면별 표시 설정을 로컬에서 보여줍니다. 사용자가 요청할 때 활성 지원 탭의 편집기/iframe/표시줄 개수와 대상 발견·가시성도 확인합니다. 원본 HTML·클래스명·텍스트·URL·계정·대화·사용량 원문은 포함하지 않고 자동 전송하거나 별도 저장하지 않습니다. `build:release`는 진단 UI와 응답 처리를 제외합니다.

앱 아이콘은 기존 `assets/logo.png`에서 준비한 로컬 PNG이고, 표시줄 게이지는 `assets/gauge-*.svg`를 번들에 포함한 인라인 SVG입니다. 런타임 외부 이미지 요청, GitHub 연결, `web_accessible_resources`는 없습니다.

백엔드·광고·추적·분석·서버 동기화·인증 우회·한도 우회는 구현하지 않습니다. 기술적 수집 가능성이 서비스 약관이나 Chrome Web Store 배포 허용을 확정하지는 않습니다.
