# AI Gauge 설치와 사용

**AI 사용량을 한눈에.** Chrome Manifest V3 · TypeScript · 브라우저 로컬 전용.

ChatGPT·Claude·Gemini 사용량을 팝업, 탭별 배지, 입력창 하단에 표시합니다. ChatGPT와 Codex 화면은 같은 OpenAI 플랜 사용량을 읽습니다. 일반 Chat 대화의 모델별 사용량을 수집한 결과가 아니며 두 화면의 값을 별도로 합산하지 않습니다.

사용자는 세 서비스의 수집 성공과 이전 ChatGPT·Claude 홈/채팅 위치, 최근 팝업 디자인을 확인했습니다. 새 입력창 외부 배치와 세부 수치·초기화 대조는 실사용 재확인이 필요합니다. [수집 가능성](provider-feasibility.md), [검증 결과](validation.md), [개발 명세](../AI_GAUGE_SPEC.md)를 참고하세요.

## 빌드와 설치

Node.js 22.22.2 이상(22.x) 또는 24.15.0 이상이 필요합니다. 테스트에 쓰는 jsdom 30의 요구 사항이며 `package.json`의 `engines`에 명시했습니다. 이 환경에서는 Node.js 24.19.0 / npm 11.9.0을 사용합니다.

```bash
npm ci
npm run check
```

1. `chrome://extensions`에서 개발자 모드를 켭니다.
2. **압축 해제된 확장 프로그램을 로드합니다**에서 `dist` 폴더를 선택합니다.
3. 최초 팝업에서 ChatGPT·Claude·Gemini 중 사용할 서비스를 선택하고 **권한 허용 및 시작**을 누릅니다. 세 서비스가 기본 선택되어 있으며 선택한 호스트 권한을 한 번에 요청합니다.
4. 승인 후 선택한 서비스가 켜지고 사용량을 조회합니다. 기존 브라우저 로그인 세션이 있으면 서비스 탭 없이도 조회를 시도합니다. 로그인이나 탭 확인 안내가 나오면 해당 서비스에 로그인한 뒤 팝업을 다시 엽니다. 갱신은 최소 60초 간격과 오류 재시도 대기를 따릅니다.

설치 시 서버나 Node.js는 필요하지 않습니다. 업데이트는 기존 폴더를 교체하고 확장과 사이트 탭을 새로고침합니다. AI Gauge는 하나만 활성화하세요. 관리되는 Chrome에서 개발자 모드가 차단되면 해당 정책 아래에서는 설치할 수 없습니다.

`npm run package`는 검증한 `dist`를 재빌드하지 않고 ZIP으로 묶습니다. `check`·브라우저 검증은 개발용 `dist`를 만들 수 있으므로 최종 ZIP 생성 직전에 `npm run build:release`와 `npm run audit:extension`을 실행합니다. ZIP 루트에는 manifest와 실행 파일, assets에는 크기별 아이콘, `_locales/en`·`_locales/ko`에는 번역 카탈로그가 들어가며 docs·INSTALL·상위 폴더는 없습니다. ZIP 드래그 설치는 이 환경에서 실측하지 못했으므로 압축을 풀고 manifest가 바로 있는 폴더를 로드하는 방법을 권장합니다.

팝업 설정의 언어 선택은 `시스템 기본 언어`, `영어`, `한국어`입니다. 기본값 `시스템 기본 언어`는 Chrome UI 언어가 한국어이면 한국어, 그 외에는 영어이며 페이지의 언어와는 독립적입니다. 직접 언어를 선택하면 저장 버튼 없이 열린 팝업과 표시줄에도 반영됩니다. 영어 초기화는 입력창과 팝업 모두 `🕒 Resets in 4 hours`로, 입력창 티켓은 `🎫 Ticket expires in 2 days`처럼 표시하고 팝업의 티켓 만료 날짜·시각은 현지 시간대를 유지합니다. 시스템 기본에서 Chrome UI 언어를 바꾼 경우에는 Chrome이 안내하는 재시작을 완료한 뒤 확인합니다.

버전과 ZIP 이름은 빌드 시작 시각의 한국 시간 `YYYYMMDDHHmm`입니다. Chrome 내부 버전만 같은 시각의 `YYYY.M.D.HHmm`으로 변환합니다. 소스 버전은 `0.0.0`으로 두고 수동으로 증가시키지 않습니다.

소스·문서는 GitHub main에서 확인할 수 있고 검증한 설치 ZIP은 기존 main의 `downloads`에 게시합니다. 앞으로 정식 배포용 ZIP만 생성·게시하며 개발용 ZIP은 새로 만들거나 갱신하지 않습니다. 개발 빌드는 필요한 로컬 검증에 사용합니다. 정식 배포용은 `npm run build:release`로 생성하며 진단 UI와 응답이 비활성화됩니다. 새 ZIP의 내용을 검증한 뒤 이전 배포용 ZIP과 README의 해당 버전·링크를 함께 교체하고 게시 후 다운로드를 확인합니다. 파일명은 `ai-gauge-YYYYMMDDHHmm.zip`이며 과거 Git 이력은 지우지 않습니다. 단순 ZIP 재배포를 위해 새 브랜치를 만들지 않으며, 동일 파일 재제공 시 원래 버전·바이트를 유지합니다.

## 사용과 표시

- 모든 서비스는 기본 비활성입니다. 모든 서비스가 꺼져 있고 권한도 없으면 체크박스 초기 설정을 표시합니다. 아무것도 선택하지 않으면 시작 버튼을 누를 수 없습니다. 새 권한 승인은 서비스를 켜는 동작까지 포함하며, 팝업이 닫혀도 백그라운드가 처리합니다. 승인을 취소하면 서비스를 켜지 않습니다.
- 한 서비스라도 켜져 있거나 권한이 있으면 기존 서비스 카드에서 각각 켜기·끄기·권한 철회를 관리합니다. 기존 권한만 있는 꺼진 서비스는 확장 재시작으로 켜지지 않습니다.
- ChatGPT와 Codex는 한 권한·수집 결과를 공유합니다. Claude와 Gemini는 별도 권한과 로그인 상태를 사용합니다. 열린 서비스 탭을 우선 사용하고 해당 서비스 탭이 하나도 없을 때만 백그라운드에서 기존 쿠키 세션으로 조회합니다. 정지·폐기된 탭이나 탭 요청 실패를 다른 계정 수집으로 대체하지 않습니다. 자동으로 숨은 탭을 열지 않습니다.
- 팝업은 기본 600px 폭, 아이콘에 맞춘 청록·파랑의 밝은/어두운 테마와 서비스별 세 카드입니다. 제목과 관리 버튼, 사용률·작은 막대·초기화를 가로로 묶어 높이를 줄이고 좁은 화면에서는 줄바꿈합니다. 신뢰할 수 없는 캐시는 짧은 상태와 `이전 수집값`으로 구분합니다.
- ChatGPT·Claude·Gemini 제목을 클릭하거나 Tab으로 선택한 뒤 Enter를 누르면 공식 홈을 새 탭으로 엽니다. 제목 모양은 그대로 두고 마우스 커서만 포인터로 표시합니다. 별도 사이트 열기와 새로고침 버튼은 없으며 사용량은 자동 갱신됩니다.
- 서비스 이름 옆 요금제 배지는 현재 확인된 요금제를 표시합니다. 미확인·기한 경과·문서 재로드로 재확인 중일 때는 배지를 숨기며 사용량은 별도로 표시합니다. 탭 선택·창 복귀·일반 채팅 경로 이동에서는 유효한 요금제를 유지합니다. 확인된 매핑과 실계정 검증 범위는 [요금제 판별](plan-detection.md)을 참고하세요.
- 설정에서 언어, 각 화면의 입력창 표시 여부, 입력창 게이지의 주의·경고 임계치를 정합니다. 저장 버튼 없이 체크박스·언어 선택은 변경 즉시, 임계치는 입력 완료 또는 Enter 때 자동 저장합니다. 임계치 기본값은 70%·90%이며 0~100 사이의 숫자(소수 허용)로 입력하고 주의 값을 경고 값보다 작게 설정합니다. 잘못된 임계치는 저장하지 않고 오류를 표시하며, 이때도 언어와 표시 여부는 변경할 수 있습니다. 저장 실패를 안내하고 저장된 값은 열린 화면에 반영합니다. 배지 대상·한도 선택·배지 임계치 색상·수집 시각·갱신 주기 설정은 없습니다.
- 첫 실행의 서비스 선택과 설정의 표시 체크박스는 기존 배지와 같은 대표색을 사용합니다. ChatGPT·Codex는 초록색, Claude는 테라코타색, Gemini는 파란색입니다.
- 배지는 **탭별**로 해당 서비스의 실제 유효 사용률 중 가장 높은 값을 표시합니다. 다른 사이트나 URL을 확인할 수 없는 탭은 비웁니다. 같은 서비스의 여러 제한을 합산하지 않습니다.
- 정상 배지는 흰색 숫자와 서비스 대표색 배경을 사용합니다. 사용률에 따라 배경색을 바꾸지 않으며 미수집·신뢰할 수 없는 값은 중립 회색의 `—`로 구분합니다.
- 입력창 표시줄은 정적 로고 대신 20px 동적 게이지를 사용하며 기존 12px 글자, 30px 높이와 작은 80×6px 막대를 유지합니다. 앱 아이콘과 팝업 로고는 그대로입니다. 좁은 공간에서는 부가 정보를 숨기고 입력을 가리지 않습니다.
- 입력창과 팝업의 정상 사용량 진행 막대도 같은 게이지 임계치와 청록색·주황색·빨간색을 사용합니다. 채워진 부분 전체를 단색 표시하며 팝업은 각 기간·모델·기능 한도 자신의 사용률로 색상을 정합니다. 저장한 임계치는 열린 화면의 막대에도 반영되고, 오류로 신뢰할 수 없는 이전 수집값은 기존 중립색 안내를 유지합니다.
- 게이지 바늘은 표시 중인 사용률에 따라 0%에서 왼쪽, 50%에서 위쪽, 100%에서 오른쪽을 가리킵니다. 원호는 기본 70% 미만에서 청록색, 70~90% 미만에서 주황색, 90% 이상에서 빨간색이며 설정의 주의·경고 값에 따라 경계가 바뀝니다. 사용률 변경 때만 바늘이 0.5초 동안 움직이고 색상은 0.3초 동안 전환됩니다. 동작 줄이기를 사용하면 전환을 끕니다. 미확인 상태는 회색 원호와 숨긴 바늘로 표시하고 정상 캐시를 유지하는 정책은 그대로 따릅니다. 동적 게이지의 실제 서비스 화면 동작은 별도 확인 대상입니다.
- 입력창 문구는 `사용량: 15%`와 `🕒 초기화: 4일 후`입니다. 남은 시간의 가장 큰 단위 하나만 내림하여 `N일 후`, `N시간 후`, `N분 후`로 표시하고 1분 미만이면 `1분 미만`을 표시합니다. 팝업의 초기화도 같은 문구와 상대 시간 형식으로 표시합니다.
- ChatGPT·Claude의 유효 초기화 티켓이 있으면 팝업에 총 보유량과 각 티켓의 만료 시각을 각각 표시합니다. 만료가 확인된 단일 티켓은 `1개`를 생략하고 `10/23(금) 15:00 만료`처럼 표시하며, 한 항목에 여러 장이 있으면 수량을 앞에 유지합니다. 항목을 가로로 배치하고 공간이 부족하면 줄바꿈하며 서로 다른 만료는 합치지 않습니다. 만료 시각을 모르는 요약은 팝업에서 개수만 표시합니다.
- 입력창에는 `🎫 티켓 만료: 2일 후`처럼 가장 먼저 만료되는 유효 티켓의 남은 시간만 표시합니다. 초기화와 같은 상대 시간 형식을 쓰며 수량·다른 날짜는 표시하지 않습니다. 만료 시각을 모르거나 수집 실패·정보 불확실 상태라면 숨깁니다. 기존 15초 표시 갱신으로 다음 티켓 만료로 전환하고 유효 티켓이 없으면 숨깁니다. 좁은 화면에서는 티켓부터 숨기며 클릭/Enter로 공식 사용량 관리 화면을 새 탭에 엽니다. ChatGPT와 Codex는 같은 티켓 정보를 사용하고 Gemini는 제외합니다. 티켓 사용은 해당 사이트에서만 직접 진행합니다.
- 실제 정상 0만 `0%`로 표시합니다. 없는 수치·시각은 확인 불가이며 오류·오래된 값을 현재 값으로 꾸미지 않습니다.
- 정상 자동 갱신은 10분이며 결과를 브라우저 로컬에 저장해 모든 열린 지원 탭에서 공유합니다. 시간 경과만으로 `오래된 정보·갱신 필요`를 표시하지 않습니다. 팝업 열기·탭 복귀·가능한 응답 완료 신호는 최소 60초 간격과 백오프를 따릅니다.
- 탭 없는 수집도 같은 갱신 주기와 캐시를 사용합니다. 실제 Chrome 쿠키 정책이나 서비스 보호 정책에 따라 로그인한 탭이 필요할 수 있습니다. 개발 환경에서는 로그인 없는 합성 응답으로 검증했으며 실계정 성공은 확인하지 못했습니다. Gemini는 기본 Google 계정만 대상으로 하며 계정을 자동 전환하지 않습니다. [상세 동작과 제한](background-collection.md)을 참고하세요.
- 유효 캐시는 첫 연결·서버 실패에도 유지합니다. 탭에서 수집 코드를 실행하지 못해도 마지막 유효 사용량을 팝업·배지·표시줄에 유지하고 자동 재시도합니다. 이 실패가 반복되어도 `사이트 접근 설정 확인` 문구로 바꾸지 않으며 유효 캐시가 없으면 수치를 만들지 않고 `사용량 다시 확인 중`으로 안내합니다.
- 연속 연결·서버 실패, 실제 로그인·권한·Claude 조직 문제, 응답 손상, 초기화 경과에는 짧은 안내를 표시합니다. 로그인·권한·조직 문제 등으로 무효화된 값은 탭 실행 실패만으로 정상값이 되지 않으며 새 수집이 성공해야 복구됩니다. 초기화 뒤의 사용량이나 다음 초기화 시각을 임의로 만들지 않습니다. 요금제·티켓의 별도 신뢰성 규칙은 그대로 유지합니다.
- 표시줄은 15초마다 남은 시간과 초기화 경과를 확인하지만 탭별로 API를 요청하지 않습니다. 막대는 소수점 수치도 반영하지만 80px 막대의 1%는 0.8px여서 작은 변화는 잘 보이지 않을 수 있습니다.
- 개발용 **진단 정보**에는 로컬 상태만 표시합니다. 정식 빌드는 진단 UI와 응답을 제외합니다.

## 데이터 해석과 Gemini 제한

ChatGPT 설정의 플랜 사용 한도는 Codex·Work·워크스페이스 에이전트·Excel용 ChatGPT가 공유하며 Chat 대화는 포함하지 않는다는 사용자 확인이 있습니다. 일반 채팅 화면에도 이 플랜 데이터를 보여줍니다. 요금제별 고정 한도, 없는 5시간 창, 크레딧 잔액은 추정하지 않습니다.

Gemini는 사용자 제공 `jSf9Qc` 웹앱 응답에 따라 5시간·주간 비율과 초기화 시각을 처리하며 사용자가 확장 내 수집 성공을 확인했습니다. `remaining`의 단위가 불명확하므로 메시지 횟수로 표시하지 않습니다. 비공개 모듈이나 별도 백엔드를 사용하지 않습니다. 토큰·계정 맥락을 안전하게 확인할 수 없으면 미지원/오류로 남기며 로그인·보호장치를 우회하지 않습니다. 다른 계정 상태와 웹앱 수치 대조는 별도 검증 대상입니다.

## 문제 해결

| 상태 | 조치 |
| --- | --- |
| 권한 필요 | 해당 서비스의 선택 호스트 권한 승인 |
| 로그인 필요 | 해당 사이트에서 로그인 후 팝업을 다시 엶. 최소 60초 간격과 재시도 대기 적용. 401만으로 로그아웃과 세션 만료를 단정하지 않음 |
| 서비스 탭 필요 | 기존 정지·폐기 탭을 활성화하거나 해당 사이트의 로그인한 탭을 열고 팝업을 다시 엶. 최소 60초 간격과 재시도 대기 적용. Gemini bootstrap을 확인할 수 없는 경우도 포함 |
| 탭 실행 실패 / 사용량 다시 확인 중 | 마지막 유효 사용량이 있으면 그대로 표시하며 자동 재시도. 캐시가 없으면 수치 없이 안내. 계속 실패하면 확장과 서비스 탭을 새로고침하고 실제 사이트 접근 권한 확인 |
| 여러 Claude 조직 | 임의 선택하지 않으므로 사이트 사용량 화면 확인 |
| 미지원 | Gemini의 토큰·계정 맥락 등 현재 처리하지 못하는 조건 확인. 자격증명을 직접 입력하지 않음 |
| 접근 거부 / 403 | 서비스의 접근 정책 확인. 우회하지 않음 |
| 요청 한도 / 429 | 자동 재시도 대기. 팝업을 다시 열어도 백오프 유지 |
| 응답 형식 확인 불가 | 내부 API 변경 가능. 개인정보·토큰·원본 응답을 이슈에 올리지 않음 |
| 표시줄 없음 | 서비스·표시 설정·권한 확인, 사이트 새로고침. 실제 DOM 셀렉터 재확인 필요 |
| 표시가 반복 이동함 | 중복 설치를 끄고 확장·사이트 새로고침 |

## 개발과 검증

```bash
npm run lint                  # TypeScript strict
npm test                      # 파서·저장·스케줄러·권한·UI 회귀
npm run build                 # 개발용 dist
npm run build:release         # 진단 UI/응답 제외
npm run audit:extension       # 권한·목적지·로컬 코드 검사
npm run package               # 검증한 정식 dist만 ZIP으로 묶음
npm run test:browser:fixture   # Chromium + 합성 DOM/Chrome API
npm run test:browser:extension # 실제 unpacked 설치 smoke
```

브라우저 실행 파일은 `CHROME_BIN`으로 지정할 수 있습니다. 합성 fixture는 실제 계정/API/설치 검증이 아닙니다. 이 클라우드 Chromium의 관리자 정책은 unpacked 로딩을 차단하므로 실제 설치 검증은 수행할 수 없습니다. 테스트 프로필만 생성·삭제하며 사용자 브라우저 프로필을 사용하지 않습니다.

기존 앱·팝업 로고는 재생성하지 않습니다. 사용자가 앱 로고를 교체한 경우에만 ImageMagick으로 `npm run prepare:icons`를 실행합니다. 일반 빌드는 준비된 PNG를 복사합니다. 입력창 게이지는 `assets/gauge-background.svg`와 `assets/gauge-needle.svg` 파일을 빌드 시 번들에 포함해 인라인 SVG로 사용하며 외부 이미지를 요청하지 않습니다. 게이지 모양을 바꾸려면 두 SVG 파일만 수정합니다.
