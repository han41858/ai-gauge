ChatGPT와 Codex는 동일한 플랜 사용량을 표시합니다. ChatGPT·Claude·Gemini의 실제 사용량 수집 성공은 사용자가 확인했습니다. 세부 검증 범위는 [검증 결과](docs/validation.md)를 참고하세요.

첫 실행에는 사용할 서비스를 체크박스로 골라 권한을 한 번에 승인합니다. 팝업은 600px 기본 폭에서 사용량과 초기화를 가로로 묶어 스크롤을 줄입니다. 서비스 탭이 없을 때에도 기존 로그인 쿠키로 조회를 시도하며, 결과는 열린 탭과 같은 로컬 캐시를 사용합니다. 탭 없는 수집의 실제 로그인 호환성은 추가 확인이 필요합니다. [동작과 제한](docs/background-collection.md)을 참고하세요.

확장 프로그램 아이콘을 누르면 팝업이 열립니다. 팝업의 서비스명 옆에는 확인된 현재 요금제를 요금제 배지로 표시하며, 확인할 수 없는 경우에는 요금제 배지를 숨깁니다. 판별 근거와 실사용 확인이 필요한 범위는 [요금제 판별](docs/plan-detection.md)에 정리했습니다.

ChatGPT·Codex·Claude·Gemini 입력창 아래에는 대표 사용량과 초기화까지 남은 시간을 보여주는 입력창 하단 표시줄이 있습니다. 표시줄의 20px SVG 게이지는 숫자·진행 막대와 같은 사용률을 표시합니다. 설정에서 주의·경고 시작 사용률을 정하며 기본값은 70%·90%입니다. 동작 줄이기 설정을 지원하고, 확인할 수 없는 사용률은 중립 상태로 표시합니다.

입력창과 팝업의 정상 사용량 진행 막대는 SVG 게이지와 같은 청록색·주황색·빨간색으로 채워집니다. 팝업의 각 기간·모델·기능 한도는 자신의 사용률을 기준으로 색상을 정하며, 기존 주의·경고 설정 변경이 함께 반영됩니다. 오류로 신뢰할 수 없는 이전 수집값은 기존 중립색과 안내를 유지합니다.

ChatGPT·Claude의 확인된 초기화 티켓은 팝업과 충분히 넓은 입력창 표시줄에 표시합니다. 티켓 링크는 공식 사용량 관리 화면을 열며 확장 프로그램에서 티켓을 소비하지 않습니다. 수량·사용 조건·계정 확인과 실사용 검증 한계는 [초기화 티켓 조회](docs/reset-tickets.md)를 참고하세요.

### 입력창 대표 사용량

ChatGPT·Codex·Claude·Gemini 입력창은 공통 한도 중 소진된 항목을 먼저 표시합니다. 여러 한도가 소진되면 가장 늦은 초기화를, 모두 미소진이면 가장 빠른 초기화를 선택합니다. 소진 한도의 초기화가 미확인이면 해당 항목을 `초기화: 확인 불가`로 표시합니다. 미소진 한도의 시각이 모두 없으면 최대 사용률을 선택하며 동률은 응답 순서입니다. 숫자·막대·바늘·색상·남은 시간은 같은 항목을 사용합니다.

모델·기능 전용 제한은 대표값에서 제외하되 팝업에는 모두 유지하며 툴바 사용량 표시는 기존 최대 사용률을 유지합니다. API가 전체 적용 관계를 제공하지 않아 실제 모든 작업의 사용 가능 여부를 보장하지 않습니다. ChatGPT와 Codex는 기존 공유 플랜 데이터를 사용합니다.
