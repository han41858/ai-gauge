# AI Gauge

**AI 사용량을 한눈에.** Chrome Manifest V3 · TypeScript · 브라우저 로컬 전용.

팝업의 **ChatGPT·Claude** 두 카드에서 사용량을 표시합니다. ChatGPT 카드의 데이터는 Work / Codex 플랜 사용량이며 일반 채팅 모델별 사용량이 아닙니다. 일반 ChatGPT와 Codex 입력창도 같은 플랜 데이터를 읽고 중복 합산하지 않습니다. Gemini는 v1.0에서 제외했습니다. 기존 Claude Tuner를 포크하지 않고 독립 구현했습니다.

> 현재는 개발자 모드 설치용 **실험적 빌드**입니다. 빌드 시각을 한국 시간 `YYYYMMDDHHmm`으로 표시합니다. 사용자는 **Work / Codex 사용량 및 Claude 사용량·리셋 시각**을 확인했고, `202610141801`에서 **ChatGPT 홈·채팅과 Claude 홈·채팅의 표시 위치가 정상**이라고 확인했습니다. 같은 빌드에서 Codex 홈·진행 중 작업에는 표시줄이 없었습니다. 이번 변경은 Codex의 `/` 리다이렉트 화면 탐색을 보강했으며 **수정 후 실제 Codex 화면은 아직 미검증**입니다. 일반 ChatGPT 모델별 수집과 공유 크레딧 잔액 표시도 완료되지 않았습니다. [수집 가능성](docs/provider-feasibility.md)과 [검증 결과](docs/validation.md)를 참고하세요.

## 빌드와 설치

Node.js 22 이상 권장. 개발 환경에서는 Node.js 24.19.0 / npm 11.9.0을 사용했습니다.

```bash
npm ci
npm run check
```

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축 해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 프로젝트의 **dist** 폴더를 지정합니다. `manifest.json`이 있는 폴더입니다.
5. AI Gauge를 툴바에 고정하고 팝업을 엽니다.

빌드 산출물에는 실행에 필요한 로컬 JS/HTML/CSS가 포함되므로 설치 시 Node.js나 서버가 필요하지 않습니다. 변경 후 `npm run build`를 실행하고 확장 관리 페이지에서 **새로고침**한 다음 사이트 탭도 새로고침하세요. 기관 관리 Chrome이 개발자 모드/압축 해제 설치를 차단하면 해당 정책 아래에서는 설치할 수 없습니다.

설치 ZIP 배포마다 새 브랜치를 만들지 않습니다. 접근 가능한 GitHub Releases 또는 기존 `main`의 `downloads/`에 검증한 ZIP만 게시하며, 현재 다운로드는 `main`의 `downloads/`를 사용합니다. **ZIP 루트에 `manifest.json`을 포함한 실행 파일 7개, `assets/`에 크기별 앱 아이콘 PNG 4개가 있으며 상위 폴더·문서·INSTALL 파일은 없습니다.** Chrome 확장 관리 화면에 ZIP을 끌어 설치하는 방식은 이 환경에서 실측하지 못했습니다. 해당 방식이 동작하지 않으면 ZIP을 폴더에 풀고 **`manifest.json`이 바로 들어 있는 폴더**를 압축 해제된 확장으로 로드하세요. 기존 설치는 같은 폴더의 파일을 교체하고 확장과 사이트 탭을 모두 새로고침합니다. 새 폴더를 별도로 로드했다면 이전 AI Gauge를 끄거나 제거하여 **활성 설치를 하나만** 유지하세요.

개발 중 수동 버전 증가는 하지 않습니다. `npm run build`는 시작 시각을 한 번 읽어 `dist/manifest.json`의 `version_name`에 한국 시간 `YYYYMMDDHHmm`을 기록합니다. ZIP 이름도 `ai-gauge-YYYYMMDDHHmm.zip`입니다. Chrome 내부 `version`만 같은 시각의 `YYYY.M.D.HHmm` 형태로 변환하며 앞자리 0을 제거합니다. 예: `202603050907` → `2026.3.5.907`. 소스의 private package와 manifest 템플릿은 `0.0.0`으로 고정합니다.

`npm run package`는 **현재 검증한 `dist`를 그대로** `artifacts/ai-gauge-{version_name}.zip`으로 묶으며 빌드를 다시 실행하지 않습니다. 이미 검증한 ZIP을 다시 제공할 때는 빌드·패키징도 다시 실행하지 않고 원본 파일의 버전과 바이트를 유지합니다. `main` 게시 시에는 원격 최신 변경을 보존하고 설치 ZIP만 추가합니다. 기본 개발 빌드에는 로컬 진단 UI와 응답 핸들러가 있습니다. `npm run build:release` 또는 `npm run build -- --release`는 이 진단 UI·핸들러를 비활성화한 배포용 산출물을 만듭니다. 배포용을 묶을 때는 해당 산출물을 검사한 뒤 package를 실행합니다.

## 사용과 표시

- 모든 서비스는 기본 비활성입니다. 필요한 사용량 카드에서 **권한 승인 및 켜기**를 누르면 승인과 동시에 해당 서비스가 켜집니다. 권한창 때문에 팝업이 닫혀도 백그라운드에서 완료합니다. Chrome 설정에서 해당 호스트 권한을 새로 승인할 때도 같은 동작이며, 기존 권한을 유지한 채 꺼둔 서비스는 워커 재시작으로 다시 켜지지 않습니다.
- 플랜 사용량은 `chatgpt.com` 권한 하나로 일반 채팅과 Codex 화면에서 함께 표시됩니다. **권한 철회**하면 해당 호스트의 수집과 두 화면의 표시가 모두 중단됩니다. 표시줄 on/off는 일반 채팅·Codex·Claude 화면별로 설정합니다.
- Work / Codex 수집에는 로그인한 `chatgpt.com` 탭, Claude 수집에는 로그인한 `claude.ai` 탭이 열려 있어야 합니다. 탭 안에서 기존 세션으로 읽기 전용 조회합니다.
- **사이트 열기**는 카드 제목에 맞춰 ChatGPT 또는 Claude를 엽니다. 일반 ChatGPT와 Codex 입력창은 동일한 `work_codex` 스냅샷을 표시하며, Claude 입력창은 Claude 데이터를 표시합니다.
- 입력창 표시는 외곽선 없이 작은 **80×6px 진행 막대**, `사용량: 15%`, `🕒 사용량 초기화: 10/16(금) 09:05, 2d 1h 남음`을 보여줍니다. 사용량과 초기화 묶음은 쉼표 대신 레이아웃 간격으로 구분합니다. 날짜와 한글 요일·24시간 시각은 브라우저 현지 시간이며, 남은 시간은 완전히 남은 일·시간입니다. 하루 미만은 `3h 남음`처럼 `0d`를 생략하고, 1시간 미만이면 `0h 남음`, 초기화가 지났으면 `초기화 시각 지남 · 갱신 필요`로 표시합니다. 없는 값은 `확인 불가`이며 이전 오류·오래된 수치를 현재 값이나 0% 막대로 표시하지 않습니다.
- 팝업의 일반 ChatGPT 실험 카드는 제거했습니다. 내부의 기능별 관찰·저장 계약은 유지하지만 일반 Chat 모델별 수집을 완료했다는 뜻은 아닙니다. 플랜 수치를 일반 채팅 수집값으로 바꾸거나 새로운 정상 수집 기록을 만들지 않습니다.
- 기본 갱신은 10분입니다. 팝업 열기·활성 탭 복귀·중지 버튼 사라짐을 감지한 응답 완료 때는 최소 60초 간격으로 조건부 갱신합니다. 응답이 그 안에 끝나면 다음 허용 시각까지 갱신을 보류합니다. 실패 시 백오프와 Retry-After를 존중하므로 수동 새로고침이 잠시 비활성일 수 있습니다. 새 수집값은 기존 진행 막대에 소수점까지 반영합니다. 80px 막대에서 1% 차이는 0.8px이므로 작은 변화나 같은 API 수치에는 눈에 띄는 움직임이 없을 수 있습니다.
- 팝업은 아이콘의 청록·파랑을 따른 밝은/어두운 테마와 파랑→청록 진행 막대를 사용하며 기존 520px의 간결한 두 카드 구성을 유지합니다. 작은 화면에서는 가로 넘침을 제한합니다. **ChatGPT·Claude** 제목 아래 실제 항목별 정보를 입력창과 같은 `사용량: N%`, `🕒 사용량 초기화: M/D(요일) HH:mm, [Xd ]Yh 남음` 형식으로 표시합니다. 입력창 텍스트는 기존 색상의 80% 농도로 강조를 낮추고 로고의 선명도는 유지합니다. 카드별 상세·항목 선택·수집 시각은 없으며 오류·미수집·오래된 데이터 안내와 필수 관리 버튼은 유지합니다. 실제 0은 `0%`, 없는 수치는 `확인 불가`입니다.
- 설정에는 **ChatGPT 입력창에 표시 / Codex 입력창에 표시 / Claude 입력창에 표시** 세 체크박스만 있습니다. 5h·7d 항목이나 배지 서비스·임계치의 수동 선택 UI는 없습니다.
- 입력창과 배지는 실제 응답의 유효한 사용률 중 **가장 높은 항목**을 자동 표시합니다. 예를 들어 7일 15%와 5시간 100%가 함께 오면 100%를 표시합니다. 동률은 응답 순서를 유지하고 없는 기간을 생성하거나 합산하지 않습니다. 팝업에는 기간·모델별 원본 항목을 각각 유지하므로 특정 모델 100%를 모든 모델 사용 불가로 단정하지 않습니다. 과거의 수동 항목 선택값은 표시에서 무시합니다.
- 배지는 **탭별로** 설정합니다. 일반 ChatGPT·Codex 탭에는 플랜 데이터, Claude 탭에는 Claude 데이터를 표시하며 다른 사이트나 URL을 확인할 수 없는 탭에는 숫자를 표시하지 않습니다. 탭 전환으로 다른 탭의 배지를 덮어쓰지 않습니다. 지원 사이트에서 수집 실패·오래됨·비활성 상태이거나 유효 사용률이 없으면 `—`로 표시합니다.
- 정상 숫자 배경은 ChatGPT/Codex 녹색 `#0D8669`, Claude 주황빛 `#B16046`이며 글자는 흰색 `#FFFFFF`입니다. 흰색 글자와의 대비는 두 배경 모두 4.53:1입니다. 사용률에 따라 배경을 경고색으로 바꾸지 않습니다. 오류·미확인 상태는 중립 회색으로 구분합니다.
- Codex는 `ComposerLayoutFooter-` class 접두사를 가진 footer의 마지막 자식, Claude는 `bg-surface-3` 안의 `relative w-full min-w-0` 또는 `mni-w-0` wrapper 바로 뒤에 삽입합니다. 허용된 `https://chatgpt.com/`에서도 명시적인 Codex footer가 있으면 Codex 화면으로 판별합니다. 구조를 찾지 못하면 가까운 composer 아래를 탐색하며 모호한 대상에는 임의로 삽입하지 않습니다. 일시 통신 실패에는 기존 표시를 유지하고, 대상 제거·숨김·비활성화·권한 철회 시 정리합니다.
- 팝업 하단에는 설치 빌드 시각이 표시됩니다. 개발 빌드의 **진단 정보 → 진단 정보 복사**에는 버전·서비스 설정·오류 코드·시각, 활성 사이트의 편집기/iframe/표시줄 개수와 대상 발견·표시 여부가 포함됩니다. 토큰·계정·URL·DOM 원문·대화·원본 응답은 포함하지 않으며 자동 전송하지 않습니다. 배포용 빌드에서는 진단 UI·응답을 비활성화합니다.
- 앱 아이콘은 GitHub main의 사용자 제공 `assets/logo.png`를 16/32/48/128px로 리사이즈해 사용합니다. 입력창 앞에는 별도 제공한 `assets/logo-20x20.png`를 그대로 번들에 포함하며 외부 이미지 요청은 없습니다. 개발 중 앱 로고를 교체할 때만 ImageMagick이 설치된 환경에서 `npm run prepare:icons`로 크기별 PNG를 갱신합니다. 일반 빌드는 준비된 PNG를 복사하므로 ImageMagick이 필요하지 않습니다.

## 수치 해석

사용자가 확인한 ChatGPT 설정의 **플랜 사용 한도** 안내는 “Codex, Work, 워크스페이스 에이전트, Excel용 ChatGPT에서 사용량 한도를 공유합니다. Chat 대화는 사용량에 포함되지 않습니다.”입니다. 입력창 위치와 수집 데이터는 별개이며 일반 채팅 화면에도 이 플랜 사용량을 표시합니다. `used_percent`는 사용한 비율입니다. 예를 들어 **15% 사용은 85% 남음**을 뜻합니다.

요금제 가격/모델명별 제한표는 코드에 없습니다. Pro $100/$200/$500에서 없는 5시간 창을 만들지 않고, API가 실제 제공한 창 길이와 초기화만 사용합니다. 7일 창만 오면 7일만 표시합니다.

모델 `available` 여부, credit unlock 가능 신호, rate-limit reset pass는 사용률·사용 크레딧 잔액이 아닙니다. 이를 임의 계산하지 않습니다. 크레딧 잔액의 실제 응답 계약은 아직 검증되지 않아 표시하지 않습니다.

## 문제 해결

| 상태 | 조치 |
| --- | --- |
| 일반 채팅에 보이는 수치가 설정의 플랜 한도와 같음 | 같은 플랜 스냅샷을 표시하는 동작입니다. Chat 대화의 모델별 사용량을 수집한 결과가 아닙니다 |
| 권한 필요 | 대상 사이트 권한을 승인해 주세요. ChatGPT·Work / Codex 권한은 공유됩니다 |
| 로그인 필요 | 사이트에서 로그인 후 수동 새로고침. 401만으로 로그아웃/세션 만료 원인을 구분하지 않습니다 |
| 서비스 탭 필요 | 수집 가능한 해당 사이트 탭을 열어 활성화하세요. 탭 부재 뒤 실제 활성화는 재시도를 시작합니다 |
| 사이트 탭에서 실행 실패 | 탭은 찾았지만 수집 스크립트를 실행하지 못한 상태입니다. 사이트 접근 허용·탭 새로고침 후 오류가 남으면 진단 코드를 확인하세요 |
| Claude 여러 조직 | 임의 조직을 선택하지 않습니다. 현재 복수 조직 수집은 미지원이며 사이트의 사용량 화면을 확인하세요 |
| 접근 거부 / 403 | 사이트/보안 설정을 확인하세요. 확장은 인증·보호장치를 우회하지 않습니다 |
| 요청 한도 / 429 | 재시도 대기 동안 새로고침이 비활성화됩니다. 잠시 후 다시 확인하세요 |
| 응답 형식 확인 불가 | 비공식 API가 바뀌었을 수 있습니다. 토큰·쿠키·개인정보가 포함된 응답을 이슈에 게시하지 마세요 |
| 표시줄이 없음 | 서비스/표시줄 설정·권한을 확인하고 탭을 새로고침하세요. 셀렉터 변경은 실사용 확인이 필요합니다 |
| Codex가 `/codex/cloud`에서 `/`로 이동한 뒤 표시되지 않음 | 명시적인 Codex footer를 기준으로 탐색하도록 수정했습니다. 실제 화면 복구는 아직 미검증이며, 재발하면 팝업의 구조 진단으로 대상 발견 여부를 확인할 수 있습니다 |
| 표시줄이 깜박임 / 업데이트가 반영되지 않음 | AI Gauge가 하나만 활성화되어 있는지, 팝업의 빌드 시각이 설치 ZIP과 일치하는지 확인하고 모든 대상 사이트 탭을 새로고침하세요 |

## 개발 및 테스트

```bash
npm run lint                  # TypeScript strict 정적 검사
npm test                      # 파서·스케줄러·상태·메시지·UI·background mock 통합
npm run build                 # dist 산출
npm run build:release         # 진단 UI/핸들러를 제외한 배포용 dist
npm run audit:extension       # 산출물 권한/목적지/원격 코드 정적 점검
npm run package               # 기존 dist의 실행 파일·로컬 아이콘만 ZIP으로 생성
npm run test:browser:fixture   # Chromium UI, Chrome API mock + 합성 DOM/데이터
npm run test:browser:extension # 관리 정책이 허용하는 Chrome에서 실제 unpacked 로딩 smoke
```

브라우저 스크립트는 `CHROME_BIN`으로 실행 파일 경로를 지정할 수 있습니다. fixture 검증은 로그인/API 수집이나 실제 확장 설치 검증이 아닙니다. 이 클라우드 Chromium의 관리자 정책은 unpacked 확장 로딩을 차단하므로 마지막 명령은 이 환경에서 실패합니다. 테스트 실행용 격리 프로필만 생성·삭제하며 사용자의 브라우저 프로필은 사용하지 않습니다. 헤드리스 컨테이너 테스트의 `--no-sandbox`는 테스트 프로세스 전용 옵션이며 확장 설치 설정이 아닙니다.

구조: `src/providers`(독립 어댑터/파서), `src/storage`, `src/background`, `src/content`, `src/popup`, `src/shared`, `tests`. SPA의 `/codex`와 `/work` 경로에 더해, 허용된 ChatGPT 호스트에서 명시적인 Codex footer 구조를 확인하면 표시 맥락을 Codex로 판별합니다. URL의 출처·권한 검증은 그대로 유지합니다. `/work` 실제 제품 경로 및 selector는 아직 실측하지 않았습니다.
